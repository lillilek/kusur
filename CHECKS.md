# Проверка подготовленной версии

- CSV: 2587 записей, без объединения повторяющихся заголовков.
- Файл CSV побайтово совпадает с исходным вложением.
- Результат JavaScript-парсера сравнен с Python csv.DictReader: все ячейки совпадают, включая пробелы и переносы строк. В 453 записях есть многострочные источники.
- Проверены все непустые заголовки на кириллице и латинице, варианты, русские и английские первые значения: каждая исходная запись находится по своему значению поля.
- Проверены точное совпадение, начало, фрагмент, значение и стабильный порядок внутри групп; комментарии и источники исключены из поиска.
- Проверены эквивалентность 1/Ӏ/ӏ, удаление ударений, дефисов, тире, скобок и апострофов; и/й, s/š и ь/ъ остаются различными.
- Обязательный тест: Б-агӀ(д)агʹуьлʹ → баг1дагуьл. Тестовая строка проверяется отдельно и не добавляется в словарь.
- Пустой запрос возвращает все 2587 записей. Несуществующий запрос возвращает ноль.
- Парсер проверен на кавычках внутри кавычек, запятых, CRLF и многострочных ячейках.
- JSON всех текстов сравнен с исходным HTML: полное совпадение. 29 файлов, 572 сегмента, 568 переводов, 332 комментария. Исходные флаги проверки сохранены.
- Проверен синтаксис JavaScript.

Ограничение проверки: визуальный просмотр и нажатия в браузере в этой среде не выполнялись. Адаптивная разметка и обработчики кнопок реализованы, но их визуальную работу стоит проверить после открытия сайта. Публикация в GitHub пользователем ещё не выполнена.
