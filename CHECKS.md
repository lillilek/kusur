# Проверки обновления от 17 октября 2026

## Источники и ограничения

- Новый `all texts_lat.zip` пуст: содержит только каталог. Латиница восстановлена из прежнего HTML, а не из новой версии латинских TextGrid.
- Кириллический архив содержит 29 TextGrid-файлов (UTF-16). Сохранены исходные строки, включая ударения, слэши, цифры 1, пробелы, кавычки и переносы строк.
- 572 старых сегмента точно совпали с новыми кириллическими по временным границам; неоднозначных соответствий нет.
- Добавлен 1 кириллический сегмент без латинского соответствия: `Cock`, 74.73947916666667–78.39525 с. Кириллица и перевод из источника сохранены; латиница не придумана.
- Сохранены 3 отдельных примечания вне транскрипции в `Wolf`.
- Всего: 29 файлов; 573 транскрибированных сегмента; 576 строк; латиница 572; кириллица 573; перевод 569; примечания 335.

## Проверки данных

- Все исходные латинские транскрипции, переводы, примечания, метки проверки и временные подписи старых сегментов сопоставлены с результатом и совпадают без изменений.
- Каждая кириллическая транскрипция из нового архива найдена в JSON с теми же границами и точным текстом.
- CSV словаря не изменён. Все ячейки результата JavaScript CSV-парсера сравнены с Python csv.DictReader: совпадение полное.
- Проверены экранированные кавычки, запятые и переносы строк внутри CSV-ячеек.

## Проверки поиска

- Проверено нахождение каждой записи по каждому непустому заголовку, варианту, русскому/английскому значению 1 и 2, комментарию, источнику, формам и первому кириллическому примеру при выборе соответствующей группы.
- Проверено нахождение каждой строки корпуса по каждому непустому полю из четырёх.
- Изолированная проверка показала, что невыбранные поля и названия файлов не влияют на результат.
- Проверены ноль выбранных столбцов, пустой запрос, отсутствие результатов, поиск по конкретному тексту, отсутствие дублирования строк, ранжирование и стабильный порядок.
- Обязательный пример «Б-агӀ(д)агʹуьлʹ» находится по «баг1дагуьл». Тестовая запись не добавлена в CSV.
- Проверены 1/Ӏ/ӏ, регистр, ударения, скобки, дефисы, апострофы; сохранение й/и, ь/ъ и специальных символов.
- Проверены включение/выключение игнорирования диакритики, š/s, ё/е в значениях.
- Регулярки: группы, альтернативы, начало/конец ячейки, классы, Unicode-свойства, экранированные скобки, ошибочный шаблон.
- Реальный код worker выполнен в Node worker_threads через адаптер Web Worker. Проверены сообщения, отмена, остановка чрезмерно долгого шаблона и успешный следующий поиск после ошибки/тайм-аута.

## Интерфейс и комплектность

- Проверен синтаксис всех JavaScript-файлов и наличие всех подключённых ресурсов.
- В модели DOM выполнены реальные скрипты обоих разделов: общая структура шапки совпадает, окно помощи открывается/закрывается, порционная выдача доходит до всех 2587 словарных и 576 корпусных строк.
- Проверены четыре колонки корпуса, 29 заголовков файлов и пояснения к пропускам.
- Визуальная проверка в браузере в этой среде недоступна. Пиксельное положение, отрисовка на конкретном телефоне и работа на опубликованном GitHub Pages здесь не проверялись.
- Обновление не содержит CSV словаря: существующий файл в репозитории должен остаться на месте.
