# Кусурский диалект: словарь и корпус

Обновление от 17 октября 2026 года. Статический сайт для GitHub Pages, без сборки и внешних библиотек.

## Как обновить уже работающий сайт

Архив `kusur-site-update.zip` содержит только файлы обновления. Таблица словаря намеренно не включена, чтобы не заменить более свежий CSV в репозитории.

1. Распакуйте архив и откройте папку `kusur-site-update`.
2. Откройте корень существующего репозитория GitHub (там, где сейчас находится `index.html`).
3. Через **Add file → Upload files** загрузите **содержимое** этой папки: HTML-файлы, папки `assets` и `data`, а также документацию. Не загружайте ZIP или внешнюю папку целиком.
4. Сохраните изменения одним коммитом в ветке, из которой публикуется GitHub Pages (обычно `main`). При загрузке заменяются одноимённые файлы; существующий `data/Kusur_dict.csv` должен остаться на месте.
5. После завершения публикации откройте сайт и обновите страницу через **Ctrl+F5**.

Настройки Pages и адрес сайта менять не нужно. Пути `index.html` и `texts.html` сохранены.

## Что изменилось

- Общая шапка, неизменное название, вкладки «Словарь / Тексты» и одна поисковая панель. Вся разметка шапки создаётся одним файлом `shared.js`; стили также общие.
- Светлый фон, голубые акценты и тонкие разделители, как у прежнего корпуса.
- Корпус: **латиница → кириллица → перевод → примечания**.
- Галочки выбирают область поиска, а не видимость столбцов. Для поиска только по одной колонке нажмите **Снять все** и отметьте её. При нескольких галочках достаточно совпадения в любом из отмеченных полей. Название файла не участвует в текстовом поиске; для него есть отдельный список текстов.
- В словаре доступны отдельные группы: кириллица, латиница, варианты, значения RU, значения EN, грамматика, формы, примеры, примечания, литературный вариант, происхождение, источники. По умолчанию включены первые пять групп, как в прежнем общем поиске. «Грамматика» объединяет pos и glossing label, «Примеры» — оба примера и их переводы.
- «Не учитывать диакритику» дополнительно снимает комбинируемые знаки, например š → s. Й не превращается в и; специальные буквы ʕ и ħ, а также ь и ъ сохраняются. Эта галочка по умолчанию выключена. В обычном поиске ударения и регистр игнорируются независимо от неё.
- В обычном поиске словаря сохраняется прежняя нормализация заголовков и вариантов: 1/Ӏ/ӏ эквивалентны, дефисы, скобки и апострофы игнорируются, буквы внутри скобок сохраняются. Точное совпадение выше начала слова, затем фрагмент, затем остальные выбранные поля. Внутри группы сохраняется порядок CSV.
- Регулярные выражения доступны в обоих разделах. Кнопка **?** открывает окно с примерами и правилами. Шаблон вводится без внешних `/…/`, применяется к каждой отдельной ячейке без учёта регистра. Скобки и другие операторы шаблона не переписываются. Результаты идут в исходном порядке. При включённом игнорировании диакритики знаки снимаются с текста, а шаблон нужно вводить уже без них.
- Неверная регулярка показывает ошибку; длительный поиск останавливается примерно через 2,5 секунды и не блокирует ввод. После этого можно очистить или изменить запрос.
- Выдача загружается порциями по 150 строк, но поиск всегда охватывает все данные.

## Какие данные включены

В `all texts_lat.zip` была только пустая папка. Поэтому **латиница взята из предыдущего `kus2026_all_texts.html`**, а кириллица — из нового `all texts_cyr.zip`. Это не новая латинская версия: если она у вас есть, её нужно будет прислать отдельно для обновления.

Все 572 прежних латинских сегмента сопоставлены с кириллическими по соответствующему тексту и совпадающим началу и концу. Названия файлов сопоставлялись без технических суффиксов `_UPDATED` и `_clean`; смысловое содержание не угадывалось и не транслитерировалось автоматически.

В новом кириллическом архиве дополнительно есть сегмент **`kus_2026_hsjn_1958_text_Cock.TextGrid`, 1:14.739–1:18.395**. Он включён вместе с переводом; латинский столбец помечен «Нет в латинском источнике».

Три примечания в `Wolf` вне интервалов транскрипции сохранены отдельными строками: 0:00.000–0:05.525; 2:35.175–2:37.640; 2:37.640–2:40.311.

Итого: **29 текстов, 573 сегмента с кириллицей (572 с латиницей) и 3 отдельные строки примечаний — 576 строк выдачи**. Перевод заполнен у 569 строк, примечание — у 335. Прежние отметки несовпадения границ сохранены.

## Как дальше обновлять словарь

Как и раньше, экспортируйте таблицу в CSV UTF-8 с разделителем запятая. Загрузите её вместо **`data/Kusur_dict.csv`**, сохранив это имя и заголовки столбцов. Строки и их порядок можно менять, дубликаты не объединяются. Код менять или пересобирать сайт не нужно. Сайт читает CSV при загрузке страницы.

## Как дальше обновлять корпус

Данные вынесены из HTML в **`data/corpus.json`**. При подготовке следующей совместимой версии корпуса достаточно заменить этот JSON. Не заменяйте новый `texts.html` старой автономной HTML-выгрузкой: она вернёт прежний интерфейс и уберёт общее оформление. Для добавления новой пары архивов TextGrid нужно сначала сопоставить интервалы и сформировать JSON в текущем формате.

## Просмотр на компьютере

На GitHub Pages сайт открывается обычной ссылкой. Для локального просмотра распакуйте обновление поверх полной прежней папки сайта (с CSV), затем откройте терминал в ней:

```text
python -m http.server 8000
```

На Windows также можно использовать `py -m http.server 8000`. Откройте `http://localhost:8000`. Запуск двойным кликом через `file://` не подходит для загрузки CSV/JSON и фонового поиска. Установка библиотек не нужна.
